# Лаборатория DynamoDB

Инструкция, ключи и ожидаемые результаты — [DynamoDB: воспроизводимая практика](../../../aws/11-практика-dynamodb.html). `01-lab.py` по умолчанию использует DynamoDB Local с фиктивными credentials; облако требует отдельного `--aws --profile ... --region ...`.

```bash
python3 examples/infra/02-dynamodb/02-test-lab.py
```

Эти шесть offline-тестов проверяют cleanup после успеха/ошибки, защиту чужой таблицы при неуспешном create и строгую проверку кода ожидаемой ошибки. Они не заменяют выполнение лаборатории против DynamoDB API.
