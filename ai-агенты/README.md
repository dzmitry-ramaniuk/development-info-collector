# AI-агенты и инструменты разработчика

## Содержание

1. [Что внутри](#что-внутри)
2. [Как изучать раздел](#как-изучать-раздел)


Раздел посвящён практической работе с AI-агентами в инженерных задачах: от базовых принципов до настройки скиллов, интеграции через MCP и выбора подходящего инструмента (GitHub Copilot, Claude, Codex).

## Что внутри

- [Работа с агентами, настройка скиллов, MCP и CLI, сравнение Copilot/Claude/Codex](01-работа-с-агентами-скиллы-mcp-cli-и-сравнение.html) — включает локальную Codex CLI лабораторную с offline MCP self-test.

## Как изучать раздел

1. Начните с общего потока работы с агентом и роли системных инструкций.
2. Пройдите [лабораторную skill + stdio MCP](01-работа-с-агентами-скиллы-mcp-cli-и-сравнение.html#лабораторная-локальный-skill-и-mcp-в-codex-cli): сначала offline-проверка сервера, затем при необходимости подключение к локальному Codex CLI.
3. Закрепите материал сравнением инструментов под ваши сценарии (IDE-автодополнение, автономная работа агента, терминальные workflow).
