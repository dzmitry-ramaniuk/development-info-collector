## 💡 Принципы оформления материалов

- **Структурированность**: Каждая тема имеет оглавление, логичную структуру разделов и последовательное изложение

- **Актуальность**: Информация обновляется с учётом современных версий технологий и best practices
- **Самодостаточность**: Каждый раздел содержит достаточно информации для понимания темы
- **Перекрёстные ссылки**: Связанные темы соединены ссылками для построения целостной картины знаний

### Паспорт актуальности

Каждый тематический файл содержит единый блок `## Актуальность материала` с датой проверки, целевой версией или диапазоном версий, статусом примеров и первичными источниками. Статусы примеров означают:

- **`current`** — примеры проверены для указанной целевой версии или диапазона и рекомендуются для новых решений;
- **`legacy`** — примеры оставлены для сопровождения существующих систем или исторического контекста и не рекомендуются как выбор по умолчанию;
- **`preview`** — примеры используют предварительные, экспериментальные или ещё не стабилизированные возможности.

Версионно-зависимые материалы рекомендуется перепроверять не реже одного раза в **6 месяцев**, а также после выхода новой major- или LTS-версии. Стабильные концептуальные страницы рекомендуется пересматривать раз в **12 месяцев**; их паспорт фиксирует дату проверки технических примеров, не ограничивая версией саму концепцию. Дату и номер версии следует указывать явно: формулировки без конкретного номера и даты не используются.
